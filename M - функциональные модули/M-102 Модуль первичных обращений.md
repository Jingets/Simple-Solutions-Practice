**M-102 Модуль первичных обращений**

**Статус:** MVP

**Приоритет:** P0 (обязательный)

**Цель**

Реализовать модуль приёма первичных обращений клиентов.

После выполнения задания платформа должна обеспечивать регистрацию нового потенциального клиента, создание карточки проекта и запуск первичного бизнес-процесса.

**Контекст**

Lead Intake является первой точкой взаимодействия клиента с платформой.

Модуль инициирует начало жизненного цикла проекта.

Модуль не выполняет анализ заявки и не принимает решений о стоимости работ.

**Технический стек**

**Backend**

- Python 3.13

- FastAPI

- SQLAlchemy

- PostgreSQL

**Frontend**

- React

- TypeScript

- Vite

**Необходимо реализовать**

**Приём заявки**

Поддержать создание новой заявки через веб-интерфейс.

**Карточка клиента**

Создавать нового клиента или связывать заявку с существующим.

**Карточка проекта**

Автоматически создавать новый проект после регистрации заявки.

**Business Event**

Создавать Business Event:

LeadRegistered

**Workflow**

Запускать Workflow первичной обработки заявки.

**Artifact**

Сохранять исходную заявку как Artifact.

**Данные заявки**

Минимальный состав данных:

- название компании;

- контактное лицо;

- телефон;

- e-mail;

- краткое описание запроса;

- источник обращения;

- дата регистрации.

**Не реализовывать**

Не входят в первую версию:

- CRM;

- автоматическую квалификацию;

- скоринг;

- AI-анализ заявки;

- интеграцию с телефонией;

- интеграцию с почтой;

- интеграцию с Telegram;

- повторные продажи.

**Архитектурные ограничения**

Lead Intake:

- не принимает решений;

- не оценивает стоимость;

- не анализирует клиента;

- не изменяет Workflow;

- только регистрирует обращение и запускает процесс.

**Definition of Done**

Модуль считается готовым, если:

- новая заявка успешно создаётся;

- клиент успешно регистрируется;

- проект автоматически создаётся;

- Business Event регистрируется;

- Workflow запускается;

- Artifact сохраняется.

**Результат**

После выполнения задания SSP получает возможность принимать реальные обращения клиентов и запускать работу по каждому новому проекту.
