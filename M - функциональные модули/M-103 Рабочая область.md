**M-103 Рабочая область**

**Статус:** MVP

**Приоритет:** P0 (обязательный)

**Цель**

Реализовать единое рабочее пространство проекта.

После выполнения задания платформа должна обеспечивать хранение всей информации, документов, результатов анализа и истории работы в рамках одного проекта.

**Контекст**

Project Workspace является центральной рабочей областью выполнения консалтингового проекта.

Все последующие бизнес-модули работают исключительно внутри Project Workspace.

**Технический стек**

**Backend**

- Python 3.13

- FastAPI

- SQLAlchemy

- PostgreSQL

**Frontend**

- React

- TypeScript

- Vite

**Необходимо реализовать**

**Создание Workspace**

Автоматически создавать рабочее пространство после регистрации нового проекта.

**Структура проекта**

Workspace должен содержать:

- карточку проекта;

- карточку клиента;

- статус проекта;

- список Artifact;

- историю Business Event;

- историю System Event.

**Хранение документов**

Workspace обеспечивает единое место хранения всех документов проекта.

**Хранение результатов**

Workspace хранит результаты Check-up, расчётов, коммерческих предложений, договоров и актов.

**История проекта**

Все изменения проекта фиксируются в хронологическом порядке.

**Навигация**

Пользователь должен иметь возможность открыть любой активный проект и увидеть его текущее состояние.

**Не реализовывать**

Не входят в первую версию:

- совместную работу нескольких сотрудников;

- комментарии;

- внутренний чат;

- версии документов;

- контроль задач;

- календарь;

- Kanban;

- уведомления.

**Архитектурные ограничения**

Project Workspace:

- не содержит бизнес-логики;

- не выполняет Workflow;

- не принимает решений;

- является контейнером данных проекта.

**Definition of Done**

Модуль считается готовым, если:

- новый Workspace автоматически создаётся;

- документы сохраняются внутри проекта;

- история проекта отображается;

- Artifact доступны из Workspace;

- состояние проекта восстанавливается после повторного открытия.

**Результат**

После выполнения задания SSP получает единое рабочее пространство проекта, через которое выполняется вся дальнейшая работа консультанта.
