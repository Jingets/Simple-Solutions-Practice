**M-108 Принципы накопления опыта**

**Принципы накопления опыта**

**OM-000**

Organizational Memory реализуется как отдельный модуль, который: 

- принимает событие ProjectClosed; 

- индексирует все Artifact проекта; 

- сохраняет их в поисковом хранилище; 

- обновляет рейтинги Artifact.

**OM-001**

Все Artifact, созданные в ходе выполнения проектов, автоматически сохраняются в Organizational Memory.

Удаление Artifact во время выполнения проекта не допускается.

**OM-002**

Organizational Memory является накопительным хранилищем практического опыта платформы.

Каждый завершённый проект увеличивает объём накопленных знаний.

**OM-003**

Оптимизация Organizational Memory выполняется периодически отдельным системным процессом.

Оптимизация не является частью выполнения проектов.

**OM-004**

Во время оптимизации система должна анализировать накопленные Artifact и выполнять:

- поиск дублирующих решений;

- объединение эквивалентных Artifact;

- снижение рейтинга редко используемых решений;

- выявление устаревших Artifact;

- архивирование неактуальных материалов;

- повышение рейтинга успешно применяемых решений.

Удаление Artifact допускается только после выполнения правил оптимизации, определённых Platform Policy.

**OM-005**

Каждый Artifact должен иметь показатели качества.

Минимальный набор показателей:

- количество использований;

- успешность применения;

- дата последнего использования;

- рейтинг;

- статус актуальности.

**OM-006**

Организационная память должна обеспечивать постепенное повышение качества базы знаний без потери подтверждённого практического опыта.

**Архитектурное правило**

Платформа не удаляет опыт.

Платформа постоянно повышает качество накопленного опыта.
