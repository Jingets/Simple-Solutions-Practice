**M-107 Оформление результатов работ**

**Статус:** MVP

**Приоритет:** P0 (обязательный)

**Цель**

Реализовать модуль завершения проекта и оформления результатов выполненных работ.

После выполнения задания платформа должна обеспечивать подготовку акта выполненных работ, закрытие проекта и передачу его в Organizational Memory.

**Контекст**

Acceptance Certificate является завершающим этапом жизненного цикла проекта.

Модуль используется после завершения всех работ по проекту.

Модуль не изменяет результаты проекта и не выполняет дополнительные работы.

**Необходимо реализовать**

**Подготовка акта**

На основании данных проекта автоматически сформировать акт выполненных работ.

Акт должен содержать:

- сведения о заказчике;

- сведения об исполнителе;

- ссылку на договор-оферту;

- перечень выполненных работ;

- дату завершения проекта;

- стоимость выполненных работ;

- реквизиты сторон.

**Регистрация документа**

Создать Artifact:

**Acceptance Certificate**

Все редакции акта сохраняются в Project Workspace.

**Закрытие проекта**

После утверждения акта автоматически изменить статус проекта:

**Project Status → Closed**

**Регистрация Business Event**

После закрытия проекта создать Business Event:

**ProjectClosed**

**Передача проекта**

После регистрации события **ProjectClosed** передать проект в модуль Organizational Memory для накопления организационного опыта.

**Не реализовывать**

Не входят в MVP:

- электронную подпись;

- интеграцию с ЭДО;

- интеграцию с бухгалтерскими системами;

- автоматическую отправку документов;

- автоматическую сверку оплат;

- повторное открытие закрытого проекта. 

В MVP проект после закрытия не может быть изменён. Любые изменения оформляются новым проектом (при необходимости).

**Архитектурные ограничения**

Acceptance Certificate:

- не изменяет результаты Check-up;

- не изменяет Estimation Report;

- не изменяет договор-оферту;

- не изменяет историю проекта;

- завершает жизненный цикл проекта и фиксирует итоговый результат.

**Definition of Done**

Модуль считается готовым, если:

- акт выполненных работ автоматически формируется;

- документ сохраняется как Artifact;

- проект переводится в статус Closed;

- создаётся Business Event ProjectClosed;

- проект автоматически передаётся в Organizational Memory.

**Результат**

После выполнения задания SSP получает возможность юридически завершить проект, оформить результаты выполненных работ и передать весь накопленный опыт в Organizational Memory для дальнейшего использования.
