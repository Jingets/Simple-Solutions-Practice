# Раздел E — Инженерная архитектура (Engineering Architecture)

## Назначение раздела

Раздел **E** содержит описание инженерной архитектуры цифровой платформы **Simple Solutions Practice (SSP)**.

Документы этого раздела определяют:
- принципы инжиниринга (Engineering Principles);
- архитектуру решений (Solution Architecture);
- технологический стек (Technology Stack);
- архитектуру бэкэнда (Backend Architecture);
- архитектуру данных (Data Architecture);
- архитектуру API (API Architecture);
- архитектуру ИИ (AI Architecture);
- архитектуру процессов и координации сервисов (Workflow & Orchestration);
- метамодель платформы (Platform Metamodel);
- модель исполнения (Execution Model);
- архитектуру артефактов (Artifact Architecture);
- архитектуру организационной памяти (Organizational Memory);
- архитектуру событий (Event Architecture);
- архитектуру модулей (Module Architecture);
- профили платформы (Platform Profiles);
- спецификацию возможностей (Capability Specification);
- Module SDK.

Все инженерные решения — выбор языка программирования, фреймворков, СУБД, облачных провайдеров, инфраструктуры и способов развёртывания — должны соответствовать принципам, описанным в данном разделе.

## Глоссарий (ключевые термины раздела E)

| Термин | Определение |
|--------|-------------|
| **Platform Kernel** | Ядро платформы, управляющее исполнением, не содержащее бизнес-логики |
| **Capability** | Минимальная единица функциональности платформы, описанная контрактом |
| **Capability Contract** | Контракт между Platform Kernel и реализацией Capability |
| **Execution Module** | Компонент, реализующий одну или несколько Capability |
| **Platform Service** | Самостоятельный сервис с собственной областью ответственности |
| **Workflow** | Управляемый процесс выполнения работы, состоящий из Task |
| **Task** | Единица работы, выполняемая одним Worker |
| **Worker** | Исполнитель (Human Worker или Cognitive Worker) |
| **Human Worker** | Человек-исполнитель |
| **Cognitive Worker** | Цифровой интеллектуальный исполнитель (AI) |
| **Artifact** | Результат завершённой деятельности, логическая бизнес-сущность |
| **Organizational Memory** | Система накопления и повторного использования опыта организации |
| **Platform Profile** | Архитектурное описание конфигурации платформы |
| **Domain** | Самостоятельная предметная область с собственной экспертной модельей |
| **Module Manifest** | Архитектурное описание модуля (ID, версия, Capability, зависимости) |
| **Transactional Outbox** | Паттерн гарантированной публикации событий через таблицу БД |
| **Event** | Зарегистрированный факт наступления события (Business/Platform/Infrastructure) |
