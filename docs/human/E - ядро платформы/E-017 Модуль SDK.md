**E-017 Module SDK**

**Версия:** 1.0

**Статус:** Draft

**Раздел:** E — Engineering Architecture

**1. Scope**

Настоящий документ определяет минимальные архитектурные требования к любому модулю платформы Simple Solutions Practice.

Module SDK является архитектурным контрактом между Platform Kernel и модулем.

Документ не зависит от языка программирования, платформы исполнения или технологии реализации.

**2. Module SDK**

Каждый модуль платформы обязан реализовывать единый Module SDK.

Module SDK определяет обязательные архитектурные точки взаимодействия с Platform Kernel.

**SDK-001**

Каждый модуль обязан поддерживать регистрацию.

**SDK-002**

Каждый модуль обязан публиковать собственный Module Manifest.

**SDK-003**

Каждый модуль обязан публиковать Capability Contract.

**SDK-004**

Каждый модуль обязан принимать Module Context.

**SDK-005**

Каждый модуль обязан возвращать Capability Result.

**Архитектурное правило**

Все модули используют единый архитектурный контракт.
