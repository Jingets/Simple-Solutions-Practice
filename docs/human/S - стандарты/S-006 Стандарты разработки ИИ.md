**S-006 Стандарты разработки ИИ**

**Статус:** MVP

**Приоритет:** P0

**Цель**

Настоящий документ определяет единый стандарт использования систем искусственного интеллекта при разработке платформы Simple Solutions Practice.

Настоящий стандарт обязателен для любых AI-систем, участвующих в проектировании, реализации, тестировании и сопровождении платформы.

**Основной принцип**

AI является инструментом разработки.

Ответственность за архитектурные решения принадлежит документации SSP.

AI не принимает архитектурных решений самостоятельно.

**Приоритет документов**

Перед началом любой работы AI обязан использовать документацию проекта в следующем порядке:

1.  Architecture (A)

2.  Engine (E)

3.  Repository (R)

4.  Module Specification (M)

5.  Standards (S)

Документ более низкого уровня не может изменять требования документа более высокого уровня.

**Недопустимые действия**

AI запрещается самостоятельно:

- изменять архитектуру платформы;

- изменять Platform Kernel;

- изменять Repository Structure;

- изменять контракты модулей;

- изменять стандарты серии S;

- добавлять новые технологии без утверждённой спецификации;

- изменять бизнес-процессы.

**Обязательный порядок работы**

Перед реализацией AI обязан:

- определить реализуемый модуль;

- изучить соответствующий документ серии M;

- определить зависимости;

- определить применимые стандарты серии S;

- подтвердить готовность к реализации.

**Реализация**

AI реализует только один модуль за одну итерацию.

Не допускается одновременная реализация нескольких независимых модулей без отдельного задания.

**Ограничение области изменений**

Изменения должны быть минимально необходимыми.

Запрещается рефакторинг несвязанных компонентов.

Запрещается изменение чужих модулей без явной необходимости.

**Соблюдение контрактов**

AI обязан соблюдать:

- Module Interface Specification;

- API Standards;

- Database Standards;

- Coding Standards;

- Testing Standards.

**Проверка соответствия**

После завершения реализации AI обязан подтвердить соответствие:

- спецификации модуля;

- стандартам разработки;

- архитектурным ограничениям;

- Definition of Done.

**Работа с неопределённостью**

Если документация не содержит необходимого правила:

AI не должен самостоятельно принимать архитектурное решение.

AI обязан:

- сообщить о недостаточности спецификации;

- предложить варианты;

- ожидать утверждения.

**Работа с документацией**

AI не имеет права изменять документы A, E, R, M и S без отдельного задания.

Документация считается первичным источником требований.

**Работа с кодом**

Каждое изменение должно:

- иметь понятную цель;

- быть локализовано;

- не нарушать существующие контракты;

- сопровождаться тестами;

- соответствовать стандартам серии S.

**Использование внешних библиотек**

Новая библиотека может быть добавлена только при выполнении всех условий:

- отсутствует эквивалент в утверждённом технологическом стеке;

- библиотека решает конкретную задачу;

- добавление согласовано;

- изменение отражено в документации.

**Работа с ошибками**

При обнаружении противоречий между кодом и документацией приоритет имеет документация.

AI не исправляет документацию автоматически.

**Отчёт о выполнении**

После завершения каждой итерации AI формирует отчёт.

Минимальный состав:

- реализованный модуль;

- изменённые компоненты;

- выполненные требования;

- невыполненные требования;

- выявленные проблемы;

- рекомендации.

**Архитектурные ограничения**

AI запрещается:

- изменять архитектуру платформы без утверждения;

- создавать скрытые зависимости;

- обходить Platform Kernel;

- обходить Repository Layer;

- обходить Artifact Manager;

- обходить Workflow Engine.

**Definition of Done**

Работа AI считается завершённой только после подтверждения:

- соответствия документации;

- успешного прохождения тестов;

- успешной проверки соответствия (Specification Compliance);

- отсутствия архитектурных нарушений.

**Главный принцип**

AI реализует платформу.

Документация управляет AI.

Архитектура SSP определяется утверждённой документацией, а не решениями используемой модели искусственного интеллекта.
