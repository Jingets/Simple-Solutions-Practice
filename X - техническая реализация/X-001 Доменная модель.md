**X-001 Доменная модель**

**Статус:** MVP

**Приоритет:** P0

**Цель**

Настоящий документ определяет доменную модель платформы Simple Solutions Practice.

Документ описывает основные бизнес-сущности платформы, их назначение, взаимосвязи и жизненный цикл.

Документ является основой для проектирования базы данных, моделей SQLAlchemy, DTO, Repository Layer и API.

**Основной принцип**

Все сущности платформы отражают реальные объекты бизнес-процесса.

Технические сущности не могут существовать без соответствующей бизнес-сущности.

**Доменные сущности MVP**

Первая версия платформы использует следующие основные сущности:

- Customer

- Lead

- Project

- Check-up

- Estimation Report

- Offer Contract

- Project Workspace

- Artifact

- Business Event

- System Event

- Acceptance Certificate

- Organizational Memory Entry

**Customer**

Представляет заказчика услуг.

Customer является владельцем одного или нескольких проектов.

Основные атрибуты:

- Customer ID

- Name

- Company

- Contacts

- Status

**Lead**

Представляет зарегистрированное обращение потенциального клиента.

Lead является входной точкой жизненного цикла проекта.

После принятия обращения Lead преобразуется в Project.

Основные атрибуты:

- Lead ID

- Customer

- Source

- Description

- Status

- Created At

**Project**

Представляет выполняемый консалтинговый проект.

Project является центральной сущностью платформы.

Все остальные бизнес-сущности относятся к конкретному Project.

Основные атрибуты:

- Project ID

- Customer

- Lead

- Status

- Created At

- Closed At

**Check-up**

Представляет результаты первичной диагностики.

Каждый Project может иметь один или несколько Check-up.

Основные атрибуты:

- Check-up ID

- Project

- Version

- Status

- Summary

**Estimation Report**

Содержит экспертную оценку объёма работ.

Создаётся на основании Check-up.

Основные атрибуты:

- Report ID

- Project

- Version

- Estimated Hours

- Estimated Cost

- Complexity

**Offer Contract**

Представляет договор-оферту.

Создаётся автоматически после утверждения оценки.

Основные атрибуты:

- Contract ID

- Project

- Version

- Amount

- Status

- Payment Status

**Project Workspace**

Является рабочей областью проекта.

Workspace объединяет все связанные материалы проекта.

Основные атрибуты:

- Workspace ID

- Project

- Status

**Artifact**

Представляет любой результат интеллектуальной работы платформы.

Artifact является самостоятельной версионируемой сущностью.

Основные атрибуты:

- Artifact ID

- Project

- Artifact Type

- Version

- Status

- Created At

**Business Event**

Фиксирует изменение бизнес-состояния платформы.

Business Event неизменяем.

Основные атрибуты:

- Event ID

- Event Type

- Project

- Context

- Timestamp

**System Event**

Фиксирует технические события платформы.

Основные атрибуты:

- Event ID

- Event Type

- Module

- Timestamp

**Acceptance Certificate**

Представляет завершение проекта.

Создаётся после выполнения работ.

Основные атрибуты:

- Certificate ID

- Project

- Version

- Status

- Created At

**Organizational Memory Entry**

Представляет запись организационной памяти.

Создаётся автоматически после закрытия проекта.

Содержит ссылки на все артефакты проекта.

Основные атрибуты:

- Memory Entry ID

- Project

- Artifact Collection

- Quality Rating

- Status

**Архитектурные ограничения**

Каждая бизнес-сущность должна:

- иметь уникальный идентификатор;

- иметь определённый жизненный цикл;

- быть связана с Project (кроме Customer и Lead);

- поддерживать аудит изменений;

- использовать единые правила версионирования при необходимости.

**Definition of Done**

Доменная модель считается утверждённой, если:

- определены все основные сущности MVP;

- определены связи между сущностями;

- определён жизненный цикл проекта;

- модель допускает автоматическую генерацию схемы базы данных, ORM-моделей и API-контрактов без изменения бизнес-смысла.

**Главный принцип**

Доменная модель описывает бизнес-платформу Simple Solutions Practice независимо от конкретной технологии хранения данных или реализации программного кода.
