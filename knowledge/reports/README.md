# Reports Knowledge Base

## Назначение

Раздел **reports** является единым источником информации о результатах консультационных услуг платформы **Simple Solutions Practice (SSP)**.

Все итоговые аналитические документы формируются исключительно на основании стандартов, определённых в настоящем разделе.

---

# Назначение раздела

Раздел определяет:

* структуру итогового отчёта;
* обязательные разделы отчёта;
* правила формирования рекомендаций;
* формат представления результатов;
* связь отчёта с проектом и оказанной услугой.

---

# Архитектурная роль

Раздел используется следующими компонентами платформы:

* Backend
* Frontend
* Report Generator
* AI Agents
* Document Engine

---

# Принцип работы

Каждый завершённый проект SSP обязан завершаться формированием итогового аналитического отчёта.

Структура отчёта определяется платформой и одинакова для всех проектов.

Конкретное содержание отчёта формируется консультантом на основании проведённой диагностики.

---

# Структура раздела

## REP

Описание итогового аналитического отчёта.

Содержит:

* назначение документа;
* структуру отчёта;
* обязательные разделы;
* машинную спецификацию;
* шаблон генерации.

# Архитектурный принцип

Итоговый отчёт является основным результатом консультационной работы SSP.

Все последующие документы (сертификат, акт и архив проекта) формируются на основании факта создания отчёта.

Редактирование структуры отчёта выполняется только посредством изменения файлов настоящего раздела.

Изменение программного кода платформы не требуется.
