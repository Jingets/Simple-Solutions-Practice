# INV — Счёт на оплату

## Назначение

INV (Invoice) является платёжным документом платформы **Simple Solutions Practice (SSP)**.

Документ автоматически формируется после создания договора-оферты (OFR) и содержит реквизиты сторон, стоимость выбранной услуги и банковские реквизиты Исполнителя.

Оплата счёта является основанием для регистрации события **OfferAccepted** и последующего создания проекта.

---

# Роль в жизненном цикле проекта

Счёт формируется сразу после создания договора-оферты.

Последовательность:

```text
Lead
    ↓
Check-up
    ↓
Proposal
    ↓
OFR
    ↓
Generate Invoice
    ↓
Payment Received
    ↓
Project Created
```

---

# Источники данных

При формировании счёта используются:

| Источник   | Назначение                       |
| ---------- | -------------------------------- |
| OFR        | Договор-оферта                   |
| PRC-001    | Стоимость услуги                 |
| Client     | Данные плательщика               |
| Contractor | Банковские реквизиты Исполнителя |
| Project    | Идентификатор проекта            |

# Результат генерации

После формирования счёта система автоматически:

* создаёт PDF счёта;
* сохраняет счёт в Workspace проекта;
* регистрирует запись счёта в базе данных;
* ожидает регистрацию оплаты.

---

# Завершение этапа

После поступления оплаты регистрируется событие:

**PaymentReceived**

После проверки оплаты система регистрирует:

**OfferAccepted**

После чего автоматически создаются:

* Project;
* Workspace.

---

# Связанные документы

Предыдущий документ:

**OFR — Договор-оферта**

Следующий этап:

Создание проекта SSP.

---

# Правила изменения

После отправки Заказчику изменение стоимости счёта не допускается.

Изменение возможно только посредством формирования нового договора-оферты и нового счёта.

---

# Архитектурный принцип

INV является автоматически генерируемым документом платформы SSP.

Счёт всегда принадлежит одному проекту и использует идентификатор **project_id** как основной ключ связи.
