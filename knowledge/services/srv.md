# SRV — Каталог услуг SSP

## Назначение

Документ определяет структуру каталога услуг платформы **Simple Solutions Practice (SSP)**.

Каталог услуг является единым источником информации для выбора услуг, формирования коммерческих предложений, договоров, счетов, проектов и итоговой документации.

---

# Архитектурная роль

Каталог услуг используется следующими компонентами платформы:

* Frontend
* Backend
* Proposal Engine
* Offer Generator
* Invoice Generator
* Project Generator
* Report Generator
* AI Agents

---

# Принцип работы

Пользователь выбирает услугу исключительно из каталога SSP.

Все последующие документы автоматически получают сведения о составе услуги, сроках выполнения и ожидаемых результатах из данного каталога.

Дублирование описаний услуг в других документах запрещается.

---

# Структура услуги

Каждая услуга содержит следующие обязательные элементы:

* идентификатор;
* код услуги;
* наименование;
* краткое описание;
* цель оказания услуги;
* состав работ;
* ожидаемые результаты;
* рекомендуемый срок выполнения;
* используемую модель ценообразования;
* статус.

---

# Использование

Каталог услуг используется в следующем процессе:

```text
Lead

↓

Выбор услуги

↓

Proposal

↓

Offer

↓

Invoice

↓

Project

↓

Report

↓

Certificate
```

---

# Связанные документы

* PRC — Матрица стоимости
* OFR — Договор-оферта
* INV — Счёт на оплату
* REP — Итоговый отчёт
* CRT — Сертификат

---

# Архитектурный принцип

Изменение состава услуг выполняется исключительно посредством изменения каталога услуг.

Изменение программного кода платформы при добавлении новой услуги не требуется.
