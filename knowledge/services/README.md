# Services Knowledge Base

## Назначение

Раздел **services** является единственным каноническим источником информации обо всех услугах платформы **Simple Solutions Practice (SSP)**.

Все документы платформы получают сведения об услугах исключительно из данного раздела.

---

# Назначение раздела

Раздел описывает:

* перечень услуг SSP;
* состав каждой услуги;
* ожидаемый результат;
* стоимость услуг;
* правила формирования коммерческого предложения;
* правила формирования договора-оферты;
* правила формирования счёта.

---

# Архитектурный принцип

В платформе отсутствуют "захардкоженные" услуги.

Backend, Frontend и AI получают сведения исключительно из каталога услуг.

Изменение состава услуг осуществляется изменением файлов данного раздела.

Изменение программного кода не требуется.

---

# Структура раздела

## SRV

Описание каталога услуг.

Содержит перечень услуг платформы и описание результатов их выполнения.

Используется:

* Frontend
* Backend
* AI
* Document Engine

---

## PRC

Матрица стоимости.

Определяет стоимость каждой услуги.

Используется:

* Proposal Generator
* Offer Generator
* Invoice Generator

---

---

# Источник данных

Для MVP каталог услуг поддерживается вручную.

В дальнейшем допускается хранение каталога услуг в базе данных при сохранении полной совместимости с настоящим разделом.

---

# Архитектурный принцип

Файлы раздела **services** являются первичным источником знаний платформы SSP.

Любой автоматически создаваемый документ использует сведения только из данного раздела.

Дублирование описаний услуг в других разделах документации запрещается.
