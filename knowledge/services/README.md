# Services Knowledge Base

## Назначение

Раздел **services** является единым источником информации обо всех консультационных услугах платформы **Simple Solutions Practice (SSP)**.

Все документы платформы получают сведения об услугах исключительно из данного раздела.

---

# Состав раздела

Раздел состоит из двух основных документов.

## SRV

Каталог услуг платформы.

Определяет:

* перечень услуг;
* описание каждой услуги;
* состав результата;
* сроки выполнения;
* статус услуги.

---

## PRC

Матрица стоимости.

Определяет:

* стоимость услуг;
* модель ценообразования;
* валюту;
* возможность индивидуального расчёта.

---

# Использование

Каталог услуг используется следующими компонентами платформы:

* Frontend
* Backend
* Proposal Generator
* Offer Generator
* Invoice Generator
* Report Generator
* AI Agents

---

# Архитектурный принцип

Каталог услуг определяет **что** продаётся.

Матрица стоимости определяет **за сколько** продаётся.

Изменение состава услуг или стоимости производится исключительно посредством изменения файлов настоящего раздела.

Изменение программного кода платформы не требуется.
