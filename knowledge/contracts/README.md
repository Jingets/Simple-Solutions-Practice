# OFR — Договор-оферта

## Назначение

OFR (Offer) является первым юридически значимым документом проекта SSP.

Документ автоматически формируется платформой после выбора клиентом услуги и подготовки коммерческого предложения.

OFR фиксирует взаимные обязательства Исполнителя и Заказчика, состав приобретаемой услуги, стоимость, сроки выполнения и ожидаемый результат.

Юридический текст договора расположен в файле **OFR.template.md**.

---

# Роль в жизненном цикле проекта

Договор-оферта создаётся после завершения подготовки коммерческого предложения.

Последовательность работы платформы:

```text
Lead
    ↓
Check-up
    ↓
Proposal
    ↓
Generate Offer
    ↓
Invoice
    ↓
Payment Received
    ↓
Project Created
```

# Результат генерации

После формирования договора система автоматически:

* создаёт PDF договора;
* сохраняет договор в Workspace проекта;
* создаёт запись договора в базе данных;
* инициирует генерацию счёта на оплату (INV).

---

# Связанные документы

Следующим документом жизненного цикла является:

**INV — Счёт на оплату**

После оплаты счёта создаётся проект SSP.

---

# Правила изменения

Редактирование сформированного договора вручную не допускается.

Изменение содержания договора осуществляется исключительно посредством изменения:

* OFR.template.md;
* данных проекта;
* каталога услуг;
* матрицы стоимости.

---

# Архитектурный принцип

OFR является автоматически генерируемым документом платформы SSP.

Главной связующей сущностью является **Project**.

Все документы проекта используют единый идентификатор проекта (`project_id`).
