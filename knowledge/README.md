# Knowledge Base

## Назначение

Knowledge Base содержит экспертные знания платформы **Simple Solutions Practice (SSP)**.

В отличие от разделов **Human Documentation**, описывающих архитектуру платформы, и **AI Guide**, определяющих правила разработки, Knowledge Base содержит бизнес-знания, используемые системой при оказании консультационных услуг.

Knowledge Base является интеллектуальным активом платформы SSP.

---

# Роль Knowledge Base

Knowledge Base используется платформой для:

* формирования диагностических вопросов;
* анализа ответов клиента;
* подготовки рекомендаций;
* генерации коммерческих предложений;
* формирования договоров;
* подготовки отчётов;
* формирования сертификатов;
* подготовки других клиентских документов.

# Принципы организации

Knowledge Base разделена на два уровня.

## 1. Базовый контент

Содержит материалы, необходимые для запуска MVP.

К ним относятся:

* каталог услуг;
* стоимость услуг;
* шаблоны договоров;
* шаблоны отчётов;
* шаблоны сертификатов;
* шаблоны коммерческих предложений;
* другие документы, необходимые для оказания услуг.

---

## 2. Экспертные знания

Содержит атомарные объекты знаний (Knowledge Objects).

Объекты знаний используются системой при диагностике бизнеса и подготовке рекомендаций.

Данный раздел развивается по мере накопления практического опыта консультирования.

---

# Представление данных

Каждый бизнес-артефакт существует в двух представлениях.

## Human Version

Документ в формате Markdown.

Используется для:

* чтения;
* обсуждения;
* экспертного редактирования;
* контроля изменений.

---

## Machine Version

Документ в формате YAML.

Используется:

* Backend;
* Frontend;
* AI-агентами;
* генераторами документов;
* системой автоматизации.

YAML является каноническим источником структурированных данных.

Markdown является человекочитаемым представлением этих данных.

---

# Правила разработки

Каждый новый бизнес-артефакт создаётся одновременно в двух форматах:

* Markdown;
* YAML.

Оба файла должны содержать одинаковую бизнес-информацию.

---

# Использование платформой

Во время работы SSP:

1. использует YAML как источник данных;
2. формирует пользовательский интерфейс;
3. генерирует документы;
4. сохраняет результаты работы проекта.

---

# Развитие базы знаний

На этапе MVP платформа использует ограниченный набор типовых документов и экспертных знаний.

После завершения каждого консультационного проекта база знаний уточняется и расширяется.

Все изменения должны быть основаны на подтверждённой практике.

Knowledge Base развивается вместе с опытом консультирования и является одним из ключевых активов платформы SSP.
