# Документация платформы Simple Solutions Practice (SSP)

## Общая информация

**Simple Solutions Practice (SSP)** — цифровая платформа экспертной практики, помогающая руководителям принимать качественные управленческие решения в условиях неопределённости.

Платформа не заменяет эксперта. Она масштабирует его практику.

**Ключевые принципы:**
- **Business First** — платформа строится вокруг бизнес-модели, а не технологий.
- **Source of Truth** — единственным источником достоверной информации являются Business Events.
- **Event Driven** — все изменения состояния инициируются событиями.
- **Automation by Design** — автоматизация сопровождает, но не заменяет эксперта.

## Ключевые термины

**SSP** — Simple Solutions Practice, цифровая платформа экспертной практики.

**Business Event** — неизменяемый факт изменения бизнес-состояния. Единственный источник достоверной информации.

**Platform Kernel** — ядро платформы, управляющее исполнением. Не содержит бизнес-логики.

**Capability** — минимальная единица функциональности платформы, описанная контрактом.

**Module** — самостоятельная единица функционального развития платформы.

**Workflow** — управляемый процесс выполнения работы, состоящий из Task.

**Artifact** — результат завершённой деятельности, логическая бизнес-сущность.

**Organizational Memory** — система накопления и повторного использования опыта организации.

**Human Worker** — человек-исполнитель, консультант.

**Cognitive Worker** — цифровой интеллектуальный исполнитель, AI.

**Pilot MVP** — минимально жизнеспособный продукт, реализующий один полный консультационный цикл.
